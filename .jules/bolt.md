## 2026-08-10 - Unaligned offset requirement in numpy
**Learning:** You cannot easily use `np.ndarray(..., buffer=data, offset=offset)` to read unstructured byte streams like GGUF metadata. `np.ndarray` and `np.frombuffer` strictly enforce that the `offset` parameter must be a multiple of the itemsize of the requested datatype. In GGUF, fields are packed tightly (often after strings of odd length) resulting in unaligned offsets, meaning these methods will immediately raise `ValueError: offset must be a multiple of the item size`. `self.data[offset:end_offs].view(dtype)` gracefully handles these unaligned views.
**Action:** When trying to read binary data from arbitrary offsets, always slice the byte array first (`data[offset:offset+len].view(dtype)`) instead of using offset-based numpy constructors unless you are mathematically certain the memory addresses are strictly aligned to type sizes.
